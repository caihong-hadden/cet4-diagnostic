# CET-4 诊断自测单页

> 四级模考做完只知道总分？这个单页告诉你错在哪个维度。

## 它解决什么

做完一套四级题，通常只知道总分，不知道**错在哪个维度**。这个单页把题目按听力、词汇、阅读分组，答完立刻给出各维度正确率与薄弱项，用于决定下一步练什么。

## 说明

纯前端实现，题目内置在页面里，不做数据上报。

## 技术栈

- **形态**：单文件 HTML，纯前端
- **维度**：听力、词汇、阅读

## 目录结构

```
  index.html
```

## 快速开始

双击 `index.html`。
